# 沙海纪年｜中东与北非历史地图

**版本：v1.2.0** · **时间范围：1797—2026**
**技术形态：原生 HTML、CSS、JavaScript、SVG；无构建步骤、无后端、无数据库**

《沙海纪年》是一份可交互的中东与北非历史地图原型。用户可以拖动时间轴，查看不同年份的疆域、政权名称、统治集团、历史事件和历史旗帜，并点击国家或争议地区进入独立详情。

项目是历史可视化工具，不是现代领土主张地图。历史边界、保护关系、军事占领、争议声索和旗帜均应结合页面的来源说明阅读。

## v1.2.0 更新重点

- 1797—2026 年时间轴播放到 2026 年后停止，不会回到 1797 年。
- 1886—1999 年接入年度历史 GIS 边界；2000—2026 年使用现代参考边界；1797—1885 年保留为概略示意。
- 加沙地带与约旦河西岸分开绘制，并按埃及、约旦、以色列、巴勒斯坦国、哈马斯控制和巴勒斯坦民族权力机构等时期切换详情。
- 西撒哈拉、巴勒斯坦使用不透明填色；戈兰高地和 1968—1979 年西奈半岛以实际控制区填色加声索方斜线表示。
- 戈兰高地、西奈半岛、汉志—内志争议区和沙特—也门未定界带可独立点击；西撒哈拉作为独立地图实体处理。
- 国家名、正式国名、执政党／统治集团、王室统治者和历史事件均可跳转中文维基百科。
- 国旗使用本地 Wikimedia Commons SVG/PNG 资源，并按当前地图边界裁切；播放时间轴时不会触发国旗悬浮。
- 摩洛哥 1886—1911 年旗帜增加主体边界裁切，并从旗帜覆盖中扣除同期单独绘制的西属摩洛哥区域。
- 疆域调试器支持 SVG、GeoJSON、JSON 和地图数据 JS 导入，保留 SVG mask 挖空路径，按完整几何签名去重，并绑定到相同疆域时期。
- `保存调试值` 同时写入浏览器和 `mena-boundary-debug.json`；支持文件选择器或浏览器下载。
- 刷新页面前会先载入疆域默认配置；项目配置文件和浏览器缓存按 `updatedAt` 选择较新版本，避免旧缓存覆盖新版 SVG。
- 根目录为工作副本，`dist/` 为同步后的发布副本。

## 使用方式

### 浏览器使用

推荐通过静态文件服务器打开，以确保默认 JSON 配置可以被浏览器正常读取：

```powershell
py -m http.server 8080
```

然后访问：

```text
http://localhost:8080/
```

也可以直接打开 `index.html`。在 `file://` 环境下，浏览器可能禁止读取同目录 JSON 文件；地图主体仍可显示，但默认调试配置可能需要依赖 localStorage 或手动导入。

### 基本操作

- 拖动底部时间轴切换年份。
- 点击播放按钮播放时间线；到 2026 年自动停止。
- 鼠标悬浮或键盘聚焦国家显示对应历史旗帜。
- 点击国家进入详情；点击“区域概览”返回区域视图。
- 点击戈兰高地、西奈半岛或其他争议地区的独立图层进入争议地区详情。
- 点击侧栏中的国家名、政权名称、统治集团或历史事件，可打开对应中文维基百科页面。
- 国家进入详情后，所选地块和国旗保持静止，其他地块仍可悬浮。

## 地图与历史边界口径

### 年度图层

- **1797—1885**：使用界面验证用的概略示意图，不作为精确历史边界或学术地图引用。
- **1886—1999**：以 CShapes 2.0 的国家／属地几何和有效期区间为主，按所选年份的 1 月 1 日生成年度快照。每个国家每年只取一个有效 cohort，同一 cohort 的多块合法领土合并。
- **2000—2026**：使用 Natural Earth 5.1.1 1:50m Cultural Vectors 现代国界参考图层。

CShapes 没有覆盖的保护国、委任统治或海湾属地，会使用明确标注来源的上下文几何或 Natural Earth 回退。页面会在资料说明中区分历史 GIS、上下文延伸和现代参考边界。

### 阿拉伯半岛历史上下文

1886—1931 年补入汉志、贾巴尔·舍迈尔和内志等在 CShapes 中没有独立现代国家记录的历史政权。相关几何主要参考 OpenGulf 的 Harita 93677 QGIS 图层，并用 1914 年阿拉伯半岛政治地图、美国国会图书馆 1920 年《Arabia》和汉志行政图交叉校核。

为避免把现代沙特轮廓倒填到早期年份，项目还做了以下处理：

- 汉志、舍迈尔和内志使用共享顶点，避免相邻历史区域重叠。
- 科威特位于 1913 年英奥边界线之外。
- 1886—1911 年利比亚采用奥斯曼的黎波里塔尼亚／昔兰尼加历史轮廓。
- 1886—1919 年从奥斯曼复合几何中裁出利比亚与汉志。
- 亚丁和东亚丁保护地单独恢复。
- 1932 年阿西尔、吉赞和纳季兰相关区域以沙特—也门未定界争议带表示，不将其直接归入已确定的沙特或也门边界。

### 西撒哈拉连续性

1958 年的完整西撒哈拉参考 SVG 被用于保持历史连续性，并应用到 1959—1975 年，避免 1959 年以后重新出现透明缺口或不完整几何。1886—1975 年西撒哈拉使用正常不透明填色；1976 年以后作为摩洛哥与波利萨里奥阵线分区控制的争议地区处理。

### 奥斯曼复合疆域

奥斯曼历史几何可能同时覆盖多个内部历史区域。项目用 SVG mask 将利比亚、汉志等区域从奥斯曼主体中裁出，并让旗帜层复用相同的挖空逻辑，避免双重填色或奥斯曼旗帜覆盖内部区域。

## 特殊地区与争议地区

### 巴勒斯坦、加沙和约旦河西岸

1949 年后，巴勒斯坦地理区域拆为加沙地带和约旦河西岸：

| 时期 | 加沙地带 | 约旦河西岸 | 侧栏详情逻辑 |
| --- | --- | --- | --- |
| 1949—1966 | 加沙地带（埃及占领） | 约旦河西岸（约旦占领） | 分别使用埃及军事管理和约旦政府／王室资料 |
| 1967—1987 | 加沙地带（以色列占领） | 约旦河西岸（以色列占领） | 分别使用以色列军事占领资料 |
| 1988—2006 | 加沙地带（巴勒斯坦国） | 约旦河西岸（巴勒斯坦国） | 共用巴勒斯坦国家详情 |
| 2007—2026 | 加沙地带（哈马斯控制） | 约旦河西岸（巴勒斯坦民族权力机构） | 再次使用不同详情 |

加沙和约旦河西岸拥有独立可点击地图图层。其 1988—2006 年侧栏通过 `sidebarEntityAt()` 映射到 `palestine`，但地图上的两个地块仍保持独立。

### 戈兰高地和西奈半岛

- 1967 年起，戈兰高地留在以色列实际控制边界内，以色列色填充，并叠加叙利亚色斜线表示声索。
- 1968—1979 年，西奈半岛留在以色列实际控制图层内，并叠加埃及色斜线表示声索。
- 鼠标从以色列移动到戈兰高地或西奈半岛时，保持以色列旗帜显示，不重复触发动画。
- 悬浮争议地区时，以色列整体旗帜显示在争议地区图层下方。
- 争议地区自身也可在疆域调试器中导入、替换和导出 SVG，并拥有独立维基链接。

### 摩洛哥与西属摩洛哥

1886—1911 年地图保留摩洛哥主体与同期西属摩洛哥上下文区域的区分。摩洛哥主体使用阿拉维苏丹国历史旗帜，西属摩洛哥使用西班牙旗帜。摩洛哥悬浮旗帜使用主体边界裁切，并扣除单独绘制的西属摩洛哥区域，避免旗帜跨越实际显示边界。

## 国旗系统

所有国旗资源作为本地 SVG 或 PNG 随项目发布，来源索引见 [`assets/flags/SOURCES.md`](assets/flags/SOURCES.md)。`modules/flags.js` 根据国家、地区和年份选择旗帜资源。

旗帜覆盖层具有以下行为：

- 使用当前国家或地区的地图路径作为 SVG 裁切边界。
- 使用 `preserveAspectRatio="xMidYMid slice"` 填充地块，不拉伸旗帜比例。
- 不添加褶皱、滤镜或伪造阴影。
- 播放时间轴时不触发旗帜悬浮。
- 进入国家详情后，所选国家保持静止。
- 奥斯曼复合路径、汉志、争议地区和西属摩洛哥分区使用相应的 mask 或独立路径。
- 旗帜离开悬浮目标后立即清理活动图层，避免旧旗帜残留。

部分保护国、委任统治或奥斯曼地方行政时期没有统一的陆上国旗。此时使用明确标注的宗主国、委任国或历史语境旗帜作为回退，不表示完整主权判断。巴勒斯坦托管地资源使用海事旗（ensign），页面会保留这一说明。

## 国旗调试器

进入国家详情后，点击侧栏右上角的“国旗调试”。面板只调整当前选中的国家和当前年份国旗资源。

可调参数：

- 横向缩放
- 纵向缩放
- 水平平移
- 垂直平移
- 旋转角度
- 背景色：地图地块本身的底色
- 国旗填充：填补原始旗帜图片未覆盖区域的颜色

### 保存方式

- **保存到浏览器**：写入当前浏览器 localStorage，键名为 `menaFlagDebugV1`。
- **保存为默认**：将当前调试结果写入 `mena-flag-debug.json`；支持文件选择器，浏览器不支持时会下载文件。保存后滑块归零，但实际缩放、平移、旋转和颜色保持不变，后续调整以新默认值为基准。
- **恢复默认**：删除当前国家／旗帜资源的个人覆盖。
- **导出 JSON**：把已保存值与当前实时未保存值合并后导出。

参数按“国家 + 具体旗帜资源”绑定，例如：

```text
morocco::morocco-alaouite.svg
egypt::egypt-1952.svg
libya::italy.svg
```

旗帜调试值的优先级为：内置参数 → `mena-flag-debug.json` → 浏览器 localStorage 的个人覆盖。奥斯曼、英国、法国、意大利和西班牙共享组使用统一的 `__sharedColors` 背景色配置。

## 疆域调试器

点击顶部的“疆域调试”打开调试器。调试器的默认配置在首次地图渲染前加载，因此刷新页面后已保存的 SVG 替换可以直接生效。

### 支持的文件

- SVG：读取可见 `<path>`，并保留通过 `mask` 表示的挖空路径。
- GeoJSON：支持 `Polygon`、`MultiPolygon` 和 `GeometryCollection`。
- JSON：支持项目配置、路径数组和带 `paths` 的导出对象。
- 地图数据 JS：读取其中的数组内容。

### 导入流程

1. 在时间轴选择需要替换的当前年份。
2. 在“调试对象”中选择国家、地区或争议地区。
3. 点击“导入文件”选择 SVG、GeoJSON、JSON 或 JS 文件。
4. 点击“导入并预览”。
5. 系统根据当前对象和年份计算实际几何时期，并将导入文件绑定到该时期。

导入不会修改原始历史数据文件。系统会在运行时跳过原始几何，使用导入的路径、填充规则和挖空路径进行替换。

### 相同 SVG 去重与时期绑定

导入文件使用以下内容生成完整签名：

- 路径 `d`
- `fill-rule`
- mask 中的挖空路径

完全相同的 SVG 只保留一份，多个时期通过 replacement 记录指向同一个 imported item。相同几何时期的文件名按“正式名称 + 起止年份”生成，例如：

```text
伊朗伊斯兰共和国1979-2026
奥斯曼帝国1886-1912
```

配置中的替换键示例：

```text
period:1886-1912::ottoman
```

### 调试参数

- 横向缩放
- 纵向缩放
- 水平平移
- 垂直平移
- 旋转
- 预览透明度

滑块旁边提供数值输入框。汉志的默认水平平移为 `+1`，作为其内置调试基准。

### 保存、恢复和导出

- **保存调试值**：写入 localStorage `menaBoundaryDebugV2`，并写入或下载 `mena-boundary-debug.json`。
- **保存为默认**：保存当前默认配置，随后将调试器滑块归零；实际路径、变换参数和已导入 SVG 不会被清除。
- **恢复默认**：删除当前对象的调试变换，回到配置中的默认值。
- **删除调试对象**：删除当前对象的调试变换或导入替换绑定。
- **导出疆域 SVG**：导出当前目标及其 mask、变换和填充信息。
- **导出路径 JSON**：导出当前目标的路径、fill rule、挖空路径和变换。
- **导出本年全部 SVG**：导出当前年份全部可见疆域。
- **导出调试配置 JSON**：导出版本 2 的完整调试配置。

`mena-boundary-debug.json` 与 localStorage 同时存在时，系统比较两者的 `updatedAt`，使用较新的配置，避免旧浏览器缓存覆盖项目中的新版 SVG。

## 国家详情与历史事件

国家详情由 `modules/core.js`、`formal-names.js`、`modules/events.js` 和 `app.js` 共同生成。

- 侧栏正式国名按当前年份变化。
- “执政党／统治集团”按时期显示政党、联合政府、王室、军政委员会、殖民当局或地方统治集团。
- 王室统治时期的统治者链接到当时在位的国王、苏丹、谢里夫或其他君主条目。
- 国家名、正式国名、执政党／统治集团和历史事件均加入中文维基百科链接。
- 选择国家或地区后，“重要历史事件”只显示该实体的事件；区域概览仍显示整个中东与北非区域事件。
- 加沙和约旦河西岸在共用巴勒斯坦详情的时期通过实体映射显示同一套国家资料，但地图对象仍然独立。

## 维护与发布

### 修改根目录

根目录是正式工作副本。修改代码、数据、配置或 README 后，同步到 `dist/`：

```powershell
powershell -NoProfile -File .\scripts\sync-dist.ps1
```

同步脚本会复制发布所需文件并检查根目录与 `dist/` 的镜像关系。

### 运行验证

```powershell
node scripts/verify.mjs
```

验证脚本检查：

- JavaScript 语法。
- HTML 中的脚本引用是否存在。
- 根目录与 `dist/` 镜像文件的 SHA-256 是否一致。
- 默认配置、历史数据、模块和资源是否完整。

预期输出类似：

```text
verify ok: 29 mirrored files, 19 JavaScript files
```

### GitHub Pages

在仓库设置中将 GitHub Pages 发布源设为 `main` 分支的根目录 `/(root)`，或发布已经同步的 `dist/` 目录。项目包含 `.nojekyll`，不需要 npm、打包器或服务器端运行时。

部署前建议确认：

- `index.html`、脚本、`assets/` 和配置 JSON 位于同一发布根目录。
- `mena-flag-debug.json` 与 `mena-boundary-debug.json` 没有被排除。
- 浏览器执行一次强制刷新，避免旧 JavaScript 或旧配置缓存。

## 已知限制

- 1797—1885 年是概略示意图，不应作为精确边界资料。
- 1886—1999 年的年度快照受历史数据有效期区间和源数据精度限制；缺失地区使用明确标注的上下文延伸。
- 国旗是历史语境视觉化，不等同于主权、承认或实际控制结论。
- 保护国、委任统治、军事占领和争议地区的颜色与旗帜需要结合侧栏说明阅读。
- 浏览器网页不能在没有授权的情况下直接覆盖项目目录；保存默认配置时，浏览器可能要求选择文件位置，或改为下载文件。
- 直接使用 `file://` 打开页面时，浏览器可能禁止读取同目录 JSON；完整调试配置工作流应使用静态服务器。
- 项目没有统一的后端数据接口；更新历史资料需要修改本地数据文件并重新同步 `dist/`。
