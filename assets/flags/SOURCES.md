## 口径说明

- 旗帜覆盖层是视觉化历史语境，不等同于对主权、承认或实际控制的判断；边界判断仍以地图数据来源说明为准。
- 部分保护国、委任统治或奥斯曼地方行政时期没有一面被普遍采用的陆上“国旗”。这些年份使用宗主国／委任国旗帜作为明确标注的上下文回退，不能解读为该宗主国拥有完整主权。
- 巴勒斯坦托管地资源是海事旗（ensign），因为当时没有统一的陆上国旗；页面将这一点写入 `data-flag-period` 和说明文档。
- 本地文件保留原始 SVG/PNG 形态，不再使用简笔画或 CSS 绘制的替代图形。
